# Welcome! 👋

I build stuff and sometimes teach others.

DevOps engineer, game designer, and a bit of a jack-of-all-trades. I spend time tinkering with my homelab and advocating for self-hosting. I'm also trying to be more open about what I'm working on and share more of what I learn!

As LLMs (or *orbuculum* to close friends) become increasingly capable, I'm exploring best practices, testing, agent harnesses, pedagogy, and custom tooling to make better use of them.

- 🌱 **Learning:** Kubernetes, Rust
- 🛠️ **Stack:** Proxmox, Docker Swarm, OpenTofu, Ansible
- 🧪 **Working on:** Sharing parts of my homelab, IaC projects, writing articles, and building custom tools (hopefully here soon! 🙂)
